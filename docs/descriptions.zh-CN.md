# 项目、Agent 与模型说明

在桌面端设置中维护供用户和 Agent 选择目标时参考的说明：

- **项目 → 选择项目 → 项目说明**：手动编辑项目用途、职责和适合处理的任务。
- **Agent → 选择 Agent → Agent 与模型说明**：在同一处编辑 Agent 及其模型的说明。模型提供方原有的说明会显示在编辑框上方，供参考。

可以直接修改或清空任一说明，然后点击“保存说明”。这些文字独立于 CLI 探测结果保存，刷新安装状态或模型列表不会覆盖它们。模型下线后说明仍会保留；相同模型 ID 再次出现时可以继续使用。

点击“总结说明”会打开生成窗口，可选择用于总结的 Agent、模型和推理强度。项目总结、Agent 与全部模型的联合总结分别提供内置 system prompt，可以编辑、保存或恢复默认 prompt。点击生成也会保存本次使用的 prompt，供同类型的下次总结使用。

生成结果回填为草稿，可以继续手动修改，点击“保存说明”后才会更新已保存的描述。取消会结束本次生成。若其他窗口修改了说明，当前草稿会保留，但保存前需要重新加载；生成过程中资料有变化时，需要重新生成。

项目总结使用项目根目录的 README、常用依赖清单、部分目录名称和现有说明，不读取聊天记录。尚未保存的项目需要先保存。Agent 与模型总结使用当前安装状态、版本、模型目录、提供方说明和现有描述；没有依据的性能、价格或能力应标为未知。生成使用独立临时会话，不接续已有聊天。

说明存储和设置界面是后续跨服务器目标发现的基础。当前功能本身不提供跨服务器任务分发、远端聊天历史读取或 MCP 跨服调用。
