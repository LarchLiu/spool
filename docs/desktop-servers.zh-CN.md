# Desktop 多服务器连接

本地服务默认保留在服务器列表中。左边栏工作区导航上方的标签用于切换服务器，
各服务器的聊天页面会保留。启动或重启 Desktop 时，所有开启 **连接当前服务器** 的
服务器都会主动连接，包括从未切换到的标签；后台连接会保留并自动重连，退出 Desktop 后关闭。
未开启的服务器保持灰色，不发起连接。当前选中的标签只决定显示哪个工作区。
本地服务仍遵循 **应用启动时开启 Spool 服务** 设置。
状态圆点在已连通且已登录时显示绿色，已连通但待登录时显示蓝色，连接中为黄色，
连接失败为红色，未连接或已停用为灰色。悬停文字会说明连接和登录状态。
已登录页面根据实时连接更新状态；待登录页面由 Desktop 定期检查服务是否仍可达，
即使页面在后台也会更新，恢复连通后重新显示蓝色。检测约每 15 秒一次，超时为 4 秒，
一次检测失败即显示红色。启动时连接失败的页面也会继续检测，服务器恢复后自动重新加载。
首次版本及会话请求的超时为 8 秒。已登录连接的 WebSocket 出错、关闭时立即报告中断，
连续 45 秒没有收到消息也会判定中断。重连没有次数上限，间隔从 0.5 秒指数增长至 30 秒，
另加最多 20% 的随机延迟；不会等到固定次数重试失败后才显示错误。
标签超过侧栏宽度时可以横向滚动，也可以按住鼠标左右拖动。**+** 位于标签列表末尾，
随列表一起滚动，切换到最后一个服务器时会同时显示 **+**。
选中背景和列表定位使用滑动动画；系统开启减少动态效果时会直接切换。
所有服务器共用左边栏宽度，调整一次后，切换服务器和重新打开 Desktop 都会沿用。
未连接或已停用的服务器也能切换到对应侧栏，通过侧栏中的 **连接**、**重试** 或
**登录** 继续操作。登录页顶部在 **设置** 同行显示当前服务器名称，返回按钮可回到侧栏。
没有账户信息时，状态文字按钮放在 **设置** 右侧；已有账户信息时，在 **设置** 左侧显示
插头（连接／登录）、重试或连接中图标。正常连接后隐藏连接按钮。

点击 **+**，在主窗口内的模态弹窗中添加服务器。显示名称可选：留空时使用服务器设置中的名称，
并跟随服务端的名称更新；填写后优先显示自定义名称，仅影响当前 Desktop。
本地服务的标签也显示它在服务器设置中配置的名称。

每个远程服务器可分别保存三种连接配置：

- **Public HTTPS**：与 PWA 相同的公网 HTTPS 地址，也可填写直接可达的本地服务 HTTP 地址。
- **Tailscale**：服务器的 HTTPS DNS 地址，通过 Desktop 内嵌节点访问。
  点击 **登录 Tailscale** 为该节点登录。
- **Spool Relay**：粘贴服务器配对码，或通过扫码按钮在本地读取配对二维码图片，
  连接后按显示的设备指纹在服务器端批准。

**连接** 会选择当前显示的连接方式。正在使用的方式显示 **断开连接**，也可取消
连接中或等待批准的配对操作，保留已保存的服务器配置。仅浏览其他连接方式的标签
不会切换连接；信息按钮可按需查看连接说明和状态。开启自动切换后，当前线路不可用时
会尝试其他已配置的方式。

登录信息按服务器配置、连接方式和目标地址分别保存。即使三种方式指向同一台
服务器，也可以分别登录不同的 Spool 账户。切换回来会恢复该方式自己的登录状态，
退出登录只影响当前方式。修改地址后使用独立会话；自动切换到其他方式时可能需要登录。

Windows、Linux 和 macOS 14 及以上版本还会为每条远程线路创建独立的原生 WebView Session，
隔离 Cookie、本地存储、缓存和 Service Worker；远程桌面窗口沿用该线路的 Session。
升级后的首次加载会先迁移该线路已有的 Cookie，再打开聊天页面；迁移成功后移除默认存储中的
旧副本，并记录迁移完成状态，避免退出登录后再次导入旧凭据。本地账户和系统通知继续使用
原来的默认存储。macOS 14 之前的命名存储无法跨启动保留数据，因此继续使用网关的 Cookie／路径隔离。
一次性冒烟测试使用仅驻留内存的 Session。

macOS 上，本地服务运行或工作区处于已连接／连接中状态时，Spool 会阻止 App Nap 限制后台活动，
窗口隐藏后仍保持服务响应；空闲或退出时释放，并允许电脑正常休眠。

聊天页的 **设置** 按钮打开当前远程服务器的连接弹窗，可修改、停用或删除配置。
停用后的标签仍可选中，并可从对应侧栏重新连接。本地服务的设置继续管理本机服务。
这些连接配置只保存在当前 Desktop，不会添加到主服务器的设置或账户偏好中。

配置保存在本机数据目录的 `desktop-servers.json` 中，每个手动添加的配置有独立 ID，
不按名称、地址或服务端 Server ID 合并。默认数据目录是 `~/.spool/`，开发版是
`~/.spool-dev/`；`SPOOL_HOME` 或 `-data-dir` 可覆盖该位置。登录 Cookie 由系统 WebView
保存，配置文件不存账号密码或登录 Cookie。

互信入口排在来源服务器后面，并使用钥匙图标。普通 B、通过 A 登录的 B、通过 D
登录的 B 分别保留自己的登录会话，互不覆盖；修改来源账号后也不会继承前一个账号的
目标会话。它们可以共用已有的 Tailscale 节点或 Relay 设备连接。通过 Relay 建立的互信
会自动获取目标线路，以独立客户端密钥接入并交换登录凭据，无需再次填写配对码、批准设备或注册目标账号；
旧的公网地址不会替代 Relay。申请时可另选对方回连本机的 Public HTTPS 或 Relay 线路，审批后自动保存。
互信设置暂时隐藏 Tailscale 通道，普通 Tailscale 连接仍可使用。点击已登录的互信
入口直接恢复缓存页面；首次登录或会话失效时，转圈表示正在核对来源授权、目标身份、
交换一次性凭据并保存目标会话。互信页面的“登录”按钮直接执行上述流程，登录期间按钮与对应标签不可重复点击。
已启用的互信配置在后台连接时确认未登录后，也会使用原来源会话自动登录，完成后保留当前选中的标签；来源账号或授权失效时停止。
普通 B 标签只使用自己的登录，不自动借用其他来源。

人员和权限在目标服务器本机管理。外部用户首次互信登录成功后，出现在目标的
**设置 → 人员** 中，带来源服务器名称、ID 和来源用户 ID；尚未登录的来源放行名单
不会同步到这里。人员编辑可停用账号、控制远程桌面和 ADB 权限，
**设置 → 项目** 可为该人员分配项目、应用内创建会话权限和共享会话权限。
远程聊天页的“设置”只管理连接；请在目标主机的 Desktop 中管理人员，或使用
[服务器 CLI](server-cli.md)。
